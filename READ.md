Employee Management System

Project Overview

The Employee Management System is a Python mini-project developed using Object-Oriented Programming (OOP) concepts. It helps store and display employee information and calculate employee salaries.

Objectives

- To understand and implement OOP concepts in Python.
- To manage employee details in an organized way.
- To calculate bonuses and total salaries.
- To practice Python classes and objects.

Features

- Store employee ID, name, department, and basic salary.
- Calculate employee bonuses.
- Calculate total salary.
- Display employee details in a readable format.

Technologies Used

- Programming Language: Python
- Development Environment: Anaconda Jupyter Notebook
- Concepts: Classes, Objects, Inheritance, and Methods

Sample Output

Employee ID: 104
Name: Shravani
Department: Sales
Basic Salary: 25000
Bonus: 2500.0
Total Salary: 27500.0

How to Run the Project

1. Download or clone this repository.
2. Open Anaconda Navigator and launch Jupyter Notebook or JupyterLab.
3. Open "Employee_Management_System.ipynb".
4. Run the notebook cells in order.

Learning Outcomes

- Learned how to create classes and objects in Python.
- Practiced using methods to calculate salary details.
- Understood how OOP concepts can organize a simple management system.
- Learned how to upload and maintain a project on GitHub.
